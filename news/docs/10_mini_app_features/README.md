# MacroHarvey — Mini App: Функціонал (Сесії 20–21)

## Загальна структура Mini App

```
Splash (1.2 сек, auto-hide)
  └── logo.png 72vw, pulse-анімація, чорний фон

App Shell
  ├── Header: лого 28px + "Новинний Дайджест" + кнопки мови/теми
  ├── Content (5 вкладок)
  └── Bottom Nav: 📰 Новини | 📋 Звіти | ➕ Додати | 📈 Ринки | 📡 Трекінг
```

Весь HTML — рядок `_WEBAPP_HTML` у `main.py`. Self-contained, ніяких зовнішніх файлів.

## Вкладка "Новини"

- Чіпи фільтрації за категоріями (All + 12 категорій)
- Картки: бейдж → заголовок → 2-рядкове саммарі → час + кнопка
- Перша підвантаження: `LIMIT 8` (для швидкості)
- Безескінечний scroll (lazy load)
- API: `GET /api/webapp/news?category=&limit=` (підтримує comma-separated категорії)
- 3 мови (UA/RU/EN): перемикання → чіпи перебудовуються, новини перезавантажуються

## Вкладка "Звіти"

- Картки: іконка типу + назва + дата/час + кнопка "📄 Відкрити"
- Типи: `☀️ Ранковий дайджест` / `🌤 Полуденне оновлення` / `📅 Тижневий звіт`
- Збереження: при надсиланні звіту → `INSERT INTO digest_reports (pdf_data BYTEA)`
- API: `GET /api/webapp/digest_reports?limit=10`
- PDF відкривається через `tg.openLink()`

## Вкладка "Трекінг" (Сесія 21)

**Крок 1 — Вибір режиму:** 2 великі кнопки — 📦 Посилка / 🚢 Контейнер

**Крок 2 — Посилки:** Сітка перевізників (Нова Пошта, DHL, EMS, Meest, Авто)

**Крок 3 — Введення номера:** input + кнопка "Знайти" (зелена)

**Анімація пошуку:** Radar з 3 пульсуючими кільцями + емодзі 📦 або 🚢

**Результат:** Timeline кроків (done/active/pending dots)

**Збережені відправлення:**
- Активні (≤15) + архівні (≤15, opacity 0.65)
- Натискання → одразу показує результат
- Кнопка ✕ → видалення

### Нова таблиця БД `tracked_shipments`

`user_id` = Telegram user ID або localStorage timestamp (анонімний режим).
`UNIQUE (user_id, number)` — один номер на користувача.

### Трекінг логіка

- ISO 6346 (4 літери + 7 цифр) → морський контейнер → 17track API
- Без `SEVENTEEN_TRACK_KEY` → `no_api: true` + `tracking_url` (посилання на сайт)
- `carrier == "nova"` або НП шаблон → `NOVA_POSHTA_API_KEY`
- DHL/EMS/Meest → 17track з кодом перевізника

## Оптимізація продуктивності

| Параметр | Було | Стало |
|---|---|---|
| Splash | 2200 мс | 1200 мс |
| Перший батч новин | 15 | 8 |
| Chart.js | `<script src="...">` | `defer` |
| Ринки при відкритті | Ціни + 3 графіки | Тільки ціни |
| Графіки | Авто | Lazy (тільки при натисканні) |

## Мови та перемикач

- 3 мови: UA (🇺🇦) / RU (🐷) / EN (🇬🇧)
- Авто-визначення з `tg.initDataUnsafe.user.language_code` або `navigator.language`
- Перемикання циклічне: натискання → наступна мова
- Всі UI-рядки у об'єкті `UI` — при змінах оновлювати ВСІ 3 мови
